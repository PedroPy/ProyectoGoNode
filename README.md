Pasos para el despliegue:
(Importante debe tener el Docker disponible para el uso)
Ejecutar el en el cmd “docker-compose up –build” (Sin comillas)
Resultado
Servidor principal: http://localhost:8080
API Go: http://localhost:3000

Frontend integrado 
Autenticación JWT

Estadísticas adicionales en Node.js 
Importante para la instalación de este código debe tener en cuenta que las versiones de Nodejs, Godeben ser las siguientes:
Node.js v24.18.0
go version go1.26.5 windows/amd64
Para que el contenedor pueda desplegar correctamente.
